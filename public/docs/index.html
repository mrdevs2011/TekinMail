TekinMail Arxitekturasi va Dasturchilar Qoʻllanmasi

TekinMail qanday qilib ogʻir SMTP serverlarsiz, faqat Cloudflare Edge, Vercel Serverless va Supabase orqali 100% real vaqtda haqiqiy xatlarni qabul qilib, brauzerda 1:1 original formatda render qiladi? Ushbu hujjat butun tizimning muhandislik yechimlarini batafsil yoritadi.

1. Infratuzilma Arxitekturasi (System Architecture)

An'anaviy email serverlar (masalan, Postfix, Exim, Dovecot) doimiy ochiq portlar, murakkab spam filtrlari va disk kvotalarini talab qiladi. TekinMail esa butunlay hodisalarga asoslangan (Event-Driven Edge) arxitekturaga qurilgan.

• 0-Disk Quota & Cheksizlik
Xatlar server diskida to'planib qolmaydi. Cloudflare xatni kelishi bilan V8 xotirasida ushlaydi va darhol JSON qilib bizning backendimizga uzatadi.
• 0.5 Soniyalik Kechikish
An'anaviy IMAP/POP3 cron polling tizimlaridagi 1-2 daqiqalik kutish o'rniga, webhook orqali xat soniya ichida foydalanuvchi ekranida paydo bo'ladi.

2. Cloudflare Email Worker Muhandisligi

Cloudflare Email Routing odatiy holatda faqat xatni shaxsiy Gmail pochtaga forward qila oladi. Lekin TekinMail foydalanuvchilari ochadigan yuzlab turli xil manzillarni boshqarish uchun biz Cloudflare email() hodisasidan foydalandik.

JavaScript (cloudflare-worker.js) 
export default {
  async email(message, env, ctx) {
    try {
      const to = (message.to || '').toLowerCase().trim();
      const from = message.from || '';
      const subject = message.headers.get('subject') || 'No Subject';
      const fromName = message.headers.get('from') || from;

      // 1. Kelgan xatning to'liq MIME xom matnini o'qib olamiz
      const rawText = await new Response(message.raw).text();

      // 2. Oddiy body matnini ajratamiz
      let bodyText = '';
      const splitBody = rawText.split(/\r?\n\r?\n/);
      if (splitBody.length > 1) {
        bodyText = splitBody.slice(1).join('\n\n');
      } else {
        bodyText = rawText;
      }

      // 3. TekinMail Vercel API backendiga JSON Webhook yuboramiz
      const targetApiUrl = env.TEKINMAIL_API_URL || 'https://tekinmail.vercel.app/api/incoming-email';

      const res = await fetch(targetApiUrl, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          to: to,
          from: from,
          from_name: fromName,
          subject: subject,
          raw: rawText,
          body: bodyText,
          html: ''
        })
      });

      console.log('TekinMail Forward Status:', res.status);
    } catch (err) {
      console.error('Error forwarding email:', err);
    }
  }
};
Muhim qoida: Cloudflare Routing Rules boʻlimida Catch-all rule yoqilgan bo'lishi va Action: Send to a Worker qilib tekinmail-receiver tanlangan bo'lishi shart!

3. MIME va Quoted-Printable Parsing Muhandisligi

Haqiqiy korporativ xatlarni (Anthropic/Claude, OpenAI, Google) qabul qilishda eng katta toʻsiq — bu MIME Quoted-Printable kodlashidir:

  • =3D belgisi aslida = ga teng;
  • Satr oxiridagi =\r\n soft line break boʻlib, havolani ikkiga boʻlib yuboradi;
  • Claude Magic Link URL kodida =3D=3D deb uzatiladi, agar u == ga dekodlanmasa, havola ishlamay qoladi.
JavaScript (api/incoming-email.js) 
// Quoted-Printable toza UTF-8 ga o'tkazish
function decodeQuotedPrintable(str) {
  if (!str) return '';
  const unsoft = str.replace(/=(?:\r\n|\n|\r)/g, ''); // Soft-breaklarni yo'qotish
  return unsoft.replace(/((?:=[0-9A-Fa-f]{2})+)/g, (match) => {
    try {
      const bytes = [];
      for (let i = 0; i < match.length; i += 3) {
        bytes.push(parseInt(match.substr(i + 1, 2), 16));
      }
      return new TextDecoder('utf-8').decode(new Uint8Array(bytes));
    } catch (e) {
      return match;
    }
  });
}

4. Supabase PostgreSQL Modeli

Ma'lumotlar bazasida 3 ta asosiy jadval mavjud. Eng muhim qoida: ON DELETE CASCADE — foydalanuvchi bitta emailni oʻchirsa, unga kelgan barcha xabarlar avtomatik va toza yoʻqoladi.

SQL (supabase-schema.sql) 
-- 1. USERS
CREATE TABLE public.users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    full_name TEXT NOT NULL,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT now() NOT NULL
);

-- 2. EMAILS (Virtual manzillar)
CREATE TABLE public.emails (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
    address TEXT UNIQUE NOT NULL,
    token TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT now() NOT NULL
);

-- 3. MESSAGES (Kelgan xatlar va HTML)
CREATE TABLE public.messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
    email_address TEXT NOT NULL,
    from_name TEXT,
    from_address TEXT,
    subject TEXT DEFAULT 'No Subject',
    body TEXT,
    html TEXT,
    is_starred BOOLEAN DEFAULT false,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT now() NOT NULL
);

6. 10-Daqiqalik Toʻliq Oʻrnatish (Step-by-Step)

1
Supabase SQL Editor'da bazani ochish

Supabase loyihangizdagi SQL Editor'ga supabase-schema.sql kodini tashlab, Run tugmasini bosing.

2
Vercel'ga deploy qilish

Loyihani GitHub orqali Vercel'ga ulab, SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY va MAIL_DOMAIN=your-domain.com oʻzgaruvchilarini kiriting.

3
Cloudflare Email Routing yoqish

Domen DNS'idan eski Ahost MX yozuvlarini o'chirib, Cloudflare Email Routing taklif qilgan 3 ta yangi MX yozuvini tasdiqlang.

4
Worker yaratish va Catch-all'ga ulash

cloudflare-worker.js kodini Cloudflare Workers'da deploy qiling va domenning Catch-all qoidasiga Send to a Worker qilib biriktiring.
